# ADRs

`NNNN-slug.md`, numbered from `0001`. Only for decisions that are hard to reverse or that a later session would plausibly reopen. Smaller choices go in the feature's Spec section.

Status is `proposed`, `accepted` or `superseded`. An accepted ADR is not edited. To reverse it, write a new ADR with `supersedes: NNNN` and set the old one to `superseded`. Start from `../_templates/adr.md`.
